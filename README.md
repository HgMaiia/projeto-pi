## Descrição dos diretórios
### `calculadoras/`
Calculadoras financeiras individuais, desenvolvidas em **JavaScript**, conforme conhecimentos adquiridos em Algoritmos.

**Como executar:**
- Abra o arquivo `.html` correspondente (dentro da pasta do aluno) no navegador.

### `Tabelas MySQL/`
Scripts de banco de dados individuais, escritos em **MySQL**, conforme conhecimentos adquiridos em Banco de Dados.

**Como executar:**
- Importe o script no MySQL Workbench.

## Requisitos

- Visual Studio Code (para executar as calculadoras financeiras)
- MySQL Server (para executar os scripts de banco de dados)
